A109 Highway Road Safety Intelligence Dashboard

Interactive GIS-Based Accident Analysis and Risk Visualization

Project Overview

Project Type: Web GIS | Transportation Analytics | Spatial Decision Support

Road accidents along major transport corridors require data-driven approaches for identifying high-risk areas and supporting targeted safety interventions.

This project developed an interactive GIS-based dashboard for the A109 Nairobi–Mombasa Highway, integrating accident locations, dangerous road sections, road network characteristics, and terrain information to visualize spatial patterns of road safety risks.

The platform transforms raw accident data into an interactive decision-support tool that enables users to explore accident distribution, identify critical locations, and understand spatial factors influencing road safety.

Project Objectives

  • Develop an interactive GIS platform for accident visualization.
  • Identify accident-prone locations along the A109 corridor.
  • Integrate road network and terrain characteristics into accident analysis.
  • Demonstrate the application of Web GIS for transport safety management.

Data Integration

Accident Dataset

Used to analyze:

  • Accident locations
  • Spatial distribution patterns
  • Accident concentration areas

Road Network Data

Integrated road characteristics including:

  • Ground roads
  • Elevated road sections
  • Embankment sections

Terrain Data

Incorporated elevation-based information:

  • Slope analysis
  • Hillshade visualization

Provides terrain context along the highway corridor.

Development Workflow

1. Data Preparation

  • Cleaned and structured accident datasets.
  • Processed spatial layers.
  • Converted datasets into web-compatible formats.

2. Spatial Database & Processing

  • Managed spatial datasets.
  • Performed spatial queries and analysis.
  • Generated map-ready layers.

3. Web GIS Development

Developed a custom interactive dashboard using:

  • Backend: Python, Flask, Spatial data processing
  • Frontend: HTML, CSS, JavaScript, Leaflet.js
  • Data Formats: GeoJSON, GeoPackage

Key Features

  • Interactive Accident Mapping: Visualizes accident locations along the highway corridor.
  • Risk Location Identification: Highlights dangerous sections requiring attention.
  • Road Classification Visualization: Displays different road characteristics influencing safety.
  • Terrain Visualization: Integrates slope and hillshade layers for landscape interpretation.
  • Interactive Exploration: Allows users to navigate, filter, and analyze spatial information.
